# 반품 마감 보드 — 온라인 쇼핑 반품 기한을 추적하세요

온라인 쇼핑 반품을 관리하도록 돕는 미니앱입니다. 법적 반품 기한(마음에 안 들 땐 7일, 결함 시 3개월)과 각 상점의 별도 정책을 자동으로 계산하고 추적할 수 있습니다. 간단한 카드 기반 인터페이스로 반품 항목을 추가하고 남은 반품 기한을 확인한 뒤 각 반품의 상태를 톡 앱 안에서 관리하세요.

## 기능

- 📦 **반품 항목 추가 및 추적** — 상품명, 상점, 수령 날짜, 반품 사유를 기록합니다
- 📅 **자동 기한 계산** — 법적 기한(마음에 안 들 땐 7일 / 결함 시 3개월)과 상점별 반품 기간을 계산합니다
- 📍 **D-day 카운트다운** — 반품 기한까지 남은 날짜를 표시합니다
- 🔄 **상태 관리** — 반품 항목을 진행 중, 반품 완료, 보관 중으로 간단한 2개 탭(진행/보관)에서 추적합니다
- 📝 **항목별 체크리스트** — 각 반품 항목마다 반품 준비 체크리스트를 유지합니다
- 🌙 **다크 모드 지원** — 톡 다크 모드를 위한 완전한 TDS 테마 통합
- 📱 **반응형 모바일 우선 디자인** — 터치와 작은 화면에 최적화됨
- 💾 **로컬 저장** — 모든 데이터를 기기 안에 저장합니다 (클라우드 불필요)

## 기술 스택

- **Framework** — Vite + React 18 + React Router 7
- **UI Components** — TDS (Toss Design System)
- **Styling** — Emotion (CSS-in-JS)
- **Icons** — lucide-react
- **Platform** — Apps-in-Toss WebView SDK
- **Testing** — Vitest + Playwright

## 시작하기

### 의존성 설치
```bash
npm install
```

### 프로덕션 빌드
```bash
npx vite build
```

### 앱인토스 배포
```bash
npx ait build
```
빌드한 번들을 톡 개발자 콘솔에 제출하여 심사 및 배포를 받습니다.

## 환경 변수

| 변수명 | 설명 | 필수 |
|----------|-------------|----------|
| `VITE_TOSS_AD_SLOT_ID` | 톡 콘솔에서 발급한 전면 광고 슬롯 ID | 아니오 |
| `VITE_TOSS_AD_GROUP_ID` | 배너 광고 그룹 ID (홈/결과 하단 배너) | 아니오 |
| `VITE_TOSS_IAP_SKU` | 톡 콘솔에서 발급한 인앱 결제 SKU | 아니오 |
| `VITE_TOSS_PROMOTION_CODE` | 톡 콘솔에서 발급한 프로모션 보상 코드 | 아니오 |
| `VITE_SHARE_OG_URL` | 공유 미리보기용 OG 이미지 URL (카카오, SMS) | 아니오 |

`.env.example`을 `.env`로 복사하고 톡 개발자 콘솔에서 얻은 값을 채워 넣으세요. 값이 비어 있으면 기능이 우아하게 축소됩니다 (흰 화면 없이 해당 섹션만 생략).

## 프로젝트 구조

```
src/
├── pages/              # 페이지 컴포넌트 (홈, 결과)
├── components/         # TDS 기반 재사용 UI (카드, 요약 히어로 등)
├── lib/               # 유틸리티 (기한 계산, 항목 저장소, 분석)
├── hooks/             # 커스텀 React 훅
├── types/             # 공유 TypeScript 타입 (env.d.ts)
├── __tests__/         # Vitest 테스트 스위트
├── styles/            # 전역 CSS
├── App.tsx            # 메인 라우팅
└── main.tsx           # 진입점
```

## 배포

**앱인토스 (톡 CDN)**

1. `apps-in-toss.config.ts`에서 `appName`이 정확한지 확인합니다 (대소문자 구분, 톡 콘솔에서 발급)
2. 빌드: `npx vite build`
3. 배포: `npx ait build` 후 톡 개발자 콘솔에 제출합니다
4. 톡 심사팀이 기기에서 테스트한 뒤 승인 또는 거부합니다
5. 승인되면 톡 미니앱 스토어에 나타나고 톡 WebView 안에서 실행됩니다

외부 호스팅은 필요 없습니다 — 톡 CDN이 빌드된 번들을 호스팅합니다.
